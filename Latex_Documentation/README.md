# Latex_Documentation

LaTeX and paper/thesis writing material.

This folder is for documentation artifacts, not for running the data or model
pipeline. The active execution flow is documented at the repository root.

## Subfolders

- `FINAL_DRAFT/`: final thesis/paper draft material and copied figures.
- `Latex/`: LaTeX source experiments or earlier write-up material.
- `PAPER_DATA/`: paper-specific data helpers and documented assets.
- `Thesis_report/`: thesis-report drafts and old report material.

Generated LaTeX build products are ignored by Git.
