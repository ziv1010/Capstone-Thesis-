# 📚 Latex_Documentation — Thesis & Paper Writing Material

> Supporting folder · LaTeX sources and figure-generation helpers for the thesis and the
> **conference paper**. This is documentation material, not pipeline code — the execution
> flow is documented at the [repository root](../README.md).

## 🗂️ Subfolders

| Folder | Purpose |
|--------|---------|
| [`PAPER_DATA/`](PAPER_DATA/README.md) | ⭐ Paper source (`main.tex`) + scripts that regenerate the pipeline diagram and early-detection figure. |
| [`FINAL_DRAFT/`](FINAL_DRAFT/README.md) | Final-draft bundle and copied figures. |
| [`Thesis_report/`](Thesis_report/README.md) | Thesis-report drafts and older report snapshots. |
| [`Latex/`](Latex/README.md) | Earlier LaTeX material (update slides). |

## 🖼️ Figure Provenance

Figures used in the documents should be traceable back to their generating pipelines:
[`section_GNN/`](../section_GNN/README.md), [`GRAPH_VISUALISER/`](../GRAPH_VISUALISER/README.md),
or [`FINAL_EXPLANATION/`](../FINAL_EXPLANATION/README.md). Refresh figures from those
folders before a final submission.

Generated LaTeX build products are ignored by Git; compact paper-ready PDFs/PNGs are kept
when they support reproducible builds.
