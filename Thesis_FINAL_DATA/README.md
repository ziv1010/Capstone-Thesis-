# Thesis_FINAL_DATA

Curated local bundle of final data snapshots used for thesis writing,
presentation figures, and manual inspection.

This is not the primary execution folder. The active pipeline remains:

```text
Fixed_GPU_OpenNyai/ -> DATA_SET_BUILDER_AND_EXPLORER/ -> section_GNN/ -> FINAL_EXPLANATION/
```

## Subfolders

- `GRAPH_INFO/`: final graph metadata, figures, or structural summaries.
- `TIMELINE/`: final timeline or merged-case snapshots.
- `embedding_analysis/`: embedding-analysis artifacts grouped by draft.
- `experiments_results/`: final experiment-result snapshots grouped by draft.

## Policy

Treat this folder as a local final-data package. It is ignored by Git because it
can contain generated figures, large tables, and copied output snapshots.
