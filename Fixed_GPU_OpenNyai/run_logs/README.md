# 🧾 run_logs — Archived Pipeline Logs

> Part of [`Fixed_GPU_OpenNyai/`](../README.md) · **generated artifacts**, safe to delete.

Historical loose logs collected here so the data folders stay focused on data artifacts:

- `final_outputs/` — run logs previously mixed into individual `final_outputs/*_extract/` folders.
- `cross_validated_outputs/` — logs previously at the top level of `cross_validated_outputs/`.

These logs are **not required** to rerun the pipeline — they are useful only for debugging or
documenting previous runs. New runs may still write logs inside their configured output
folder; move long-term logs here when archiving.
