# src

Shared helper modules for the `Fixed_GPU_OpenNyai` pipeline.

The top-level scripts import these modules for:

- configuration and repository-relative path handling
- JSON and text I/O helpers
- output formatting
- pipeline orchestration
- validation checks

Users should normally run the top-level scripts or wrappers in
`Fixed_GPU_OpenNyai/run_scripts/` rather than calling modules here directly.
