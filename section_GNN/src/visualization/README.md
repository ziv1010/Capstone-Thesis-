# src/visualization

Visualization helpers for graph inspection and final figures.

## Files

- `graph_visualizer.py`: reusable graph visualisation utilities.
- `final_visualizer.py`: higher-level visualisation helpers for final outputs.

These modules are support code. Most user-facing visualisation workflows are in
`embedding_analysis/`, `final_graph/visualize_graph_structure.py`, or
`multi_hearing_stage_test/visualiser/`.
