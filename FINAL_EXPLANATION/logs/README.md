# Logs

Loose runtime logs for `FINAL_EXPLANATION` are collected here so the root folder
stays focused on source files and documentation.

These files are not required to rerun the pipeline. They are useful for checking
previous visualizer sessions or debugging prior runs.

Generated per-shard logs remain inside the relevant output directory, for
example:

```text
outputs/<run_name>/logs/
outputs/<run_name>/validation_logs/
```
