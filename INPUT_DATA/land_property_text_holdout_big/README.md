# 🧪 Land & Property — Big Holdout Text Set

> Part of [`INPUT_DATA/`](../README.md) · **Stage ①** of the pipeline.

Large **held-out** plain-text judgment set for **land, property, and revenue disputes (title, partition, tenancy, acquisition)**, kept separate from the main
training corpus.

- 🎯 **Purpose:** auxiliary and cross-domain evaluations (e.g. `section_GNN/cross_domain_test/`),
  never mixed into the five-domain GNN training data.
- 🚫 **Git policy:** local data only — this folder's contents are ignored by Git.
