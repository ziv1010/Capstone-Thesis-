# Paper Data

LaTeX and figure-generation assets for the thesis paper.

## Contents

- `main.tex`: paper source.
- `make_pipeline_diagram.py`: regenerates the pipeline diagram.
- `make_early_detection_figure.py`: regenerates the early-detection signal figure.
- `gnn_embedding_comparison_full.csv`: compact table used by paper figures.

Generated PDFs and PNGs in this folder are small paper artifacts and are kept in Git when useful for reproducible paper builds.
